Printer compatibility

What has been tested on real printers, from the Nozzle Test Grid: owners run standard tests in the app's Test Mode and send the results, and each result is reviewed before it counts here.

Each printer and firmware is graded on its own; a result on one firmware says nothing about another. Pass means every test in that category passed on a real printer. Not tested means there is no accepted result for it yet, not that it doesn't work. Multi-material printing is graded separately from single-material printing.
