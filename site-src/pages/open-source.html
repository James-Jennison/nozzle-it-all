The slicing engine

The on-device slicer is built from OrcaSlicer, which is also AGPL-3.0. We pin the exact upstream version and apply a patch so it runs headless on Android:

  • Upstream commit: 824b216f1823
  • Our patch and the pin file, which also records the dependency archives and their checksums.

Building it

The repository's README explains how to build the Android app with Gradle and how to prepare the pinned engine. A script in the repository checks that an engine checkout matches the pin.

If you use it over a network

The AGPL asks that people who use modified versions over a network can get the source of that version. If you run a modified copy of any part of Nozzle It All (for example a modified copy of Nozzle It All Web hosted for other people), you need to offer its source to its users. The licence text says exactly how.
