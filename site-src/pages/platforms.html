Platforms

Android is the only version that exists today. It is in invite-only closed testing on Google Play and is not yet publicly available. Everything else on this page is a plan, listed in the order we intend to build it. Nothing below is available to download or launch.

{{platform_cards}}

Android {{status:android}}

The full app: on-device slicing, printer control at home over Wi-Fi or away over mobile data through a private connection you choose, model discovery and background alerts. Nozzle It All connects directly to the printer address you configure and does not relay printer traffic through its own server. It is in invite-only closed testing on Google Play and is not yet publicly available. To hear when it is, follow the releases on GitHub.

See the remote-access options and setup guidance.

Want to try it early? Email us to request a spot in the closed test and include the Google account address you use on Google Play. We add people by hand, so it can take a little while. How the test works.

Linux desktop {{status:linux}}

Planned first after Android. It will run the same slicing engine as a local worker process, and it doubles as the local agent that the web app connects to.

Web app {{status:web}}

Planned second. It is not a hosted cloud slicer: it needs an engine you run yourself. How the web app is planned to work.

Windows desktop {{status:windows}}

Planned after the web app, built on the same engine as the Linux version.

iOS and macOS {{status:ios}}

Deferred, which means paused rather than cancelled. There is no plan or timeline to announce.

Order and status are the current intention and can change. This page is updated when something is actually released.
