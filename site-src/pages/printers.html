Supported printers

Nozzle It All connects to the printers you own over your own network. We are honest about how sure we are, so every printer type below is one of two things:

Verified on hardware we have run it on a real printer of this kind.
Built from vendor docs written against the vendor's published protocol and tested against an emulator or test server, but not yet on a real printer. It may work well, and it may not. If you try one, please tell us what happened.

Printer or firmwareStatusWhat it does
Klipper with MoonrakerVerified on hardware Status, temperatures, progress, start, pause and cancel, file browser, macros, camera, jog, bed levelling, timelapse and filament load and unload, each shown only if the printer reports it. Sliced files can be sent to it.
Snapmaker U1 (PAXX firmware)Verified on hardware Everything above, plus its multi-tool features. A bundled slicing profile is included. Bespok3d, an add-on manager for the printer, does not work on this firmware.
Snapmaker U1 (stock firmware)Built from vendor docs The same controls and slicing profile as the PAXX row, plus optional pairing with Bespok3d, which only works on stock firmware. The app has not yet been run on a stock-firmware U1, only on a PAXX one, so treat it as untested and tell us how it goes.
Elegoo Centauri Carbon running OpenCentauriVerified on hardware Works as a Klipper-style printer with a bundled slicing profile. You confirm the firmware version once, because slicing with the wrong profile can stop a print on some firmware.
Bambu Lab (LAN mode)Built from vendor docs Status, pause, resume and stop, sending a sliced file, and the chamber camera, over the printer's local network. Needs LAN mode, the printer's serial number and access code. The app remembers each printer's certificate the first time it connects and warns you if it later changes. Tested against an emulator only.
OctoPrintBuilt from vendor docs Status, temperatures, progress, start, pause and cancel, and sending a sliced file, using an API key. Tested against a real OctoPrint server, but not with a physical printer attached. No camera.
PrusaLinkBuilt from vendor docs Status, progress and controls, using the PrusaLink password. No camera. A bundled Prusa slicing profile exists, also untested on a real printer.

Have one of these printers? Help us test it. See every printer model with a bundled slicing profile (376 models from 60 makers). Slicing works for all of them; connecting to and controlling a printer is limited to the types in this table.

Something not on the list?

If your printer runs Klipper with Moonraker, it will very likely work as "Klipper with Moonraker" even if the model is not named here. Tell us what you find at {{email}}, or open an issue.
