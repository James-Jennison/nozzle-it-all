Supported printers

Nozzle It All connects to the printers you own over your own network. We are honest about how sure we are, so every printer type below is marked with one of these:

Verified on hardware we have run it on a real printer of this kind.
Built from vendor docs written against the vendor's published protocol and tested against an emulator or test server, but not yet on a real printer. It may work well, and it may not. If you try one, please tell us what happened.
Built from open-source slicer code ported from the maker's or OrcaSlicer's published source and tested against simulated printers, also not yet on a real printer.
Next update in the app's next update, not in the version you can install today.

For test results per printer model and firmware, category by category, see Printer compatibility.

Printer or firmwareStatusWhat it does
Klipper with MoonrakerVerified on hardware Status, temperatures, progress, start, pause and cancel, file browser, macros, camera, jog, bed levelling, timelapse and filament load and unload, each shown only if the printer reports it. Sliced files can be sent to it. Filament changers are read when present (AFC / Box Turtle, Happy Hare / ERCF, Qidi Box), and multi-colour files can be sliced for them. Verified on the Snapmaker U1 and the Centauri Carbon on COSMOS; other Klipper printers are listed as waiting for testers on the compatibility page.
Snapmaker U1 (PAXX firmware)Verified on hardware The primary platform. Everything above, plus its four toolheads: the material loaded in each one, Full Spectrum colour mixing and multiACE. Works entirely on your own network with no Snapmaker account, cloud or internet connection; away from home, connect through your own private network such as Tailscale. A bundled slicing profile is included; single- and multi-colour printing passed on a real U1, with its adaptive bed mesh (results). Bespok3d, an add-on manager for the printer, does not work on this firmware.
Snapmaker U1 (stock firmware)Built from vendor docs Monitoring, controls, sending jobs and the slicing profile over your own network, plus optional pairing with Bespok3d on Android. Some stock-firmware features exist only through Snapmaker's own cloud; on Desktop those will come through optional Stock U1 support, installed separately and only started if you add a Stock U1. If it fails, your PAXX printers are unaffected. Nothing here has been run on a stock-firmware U1 yet, so treat it as untested and tell us how it goes.
Elegoo Centauri Carbon running OpenCentauri COSMOSVerified on hardware Add it as a Klipper printer and choose the COSMOS profile (the CANVAS one if you have CANVAS); the app checks the firmware version, because slicing with the wrong profile can stop a print. Single-colour printing and two-colour printing with CANVAS, with a wipe tower and COSMOS's adaptive bed mesh, passed on a real printer on COSMOS 26.09 (results). OpenCentauri's patched stock firmware is a different thing and is not tested yet.
Elegoo on Elegoo firmware Next updateBuilt from vendor docs Centauri Carbon (SDCP) and Centauri Carbon 2 (MQTT, with its access code): status, CANVAS lanes, sending and starting a sliced file, and cancel; pause and resume on the Centauri Carbon only. No camera. Tested against simulated printers only.
Bambu Lab (LAN mode)Built from vendor docs Status, pause, resume and stop, and sending a sliced file, over the printer's local network. The camera works on the A1 and P1 series; the X1 and H2 series use a camera stream Nozzle It All can't show yet. Needs LAN mode, the printer's serial number and access code. The app remembers each printer's certificate the first time it connects and warns you if it later changes. The AMS slots (AMS, AMS lite, AMS 2 Pro, AMS HT) are read and multi-colour files can be sliced, but multi-colour printing is not switched on yet: until it has been checked on a real printer, a multi-colour file is refused at the start. Tested against an emulator only.
OctoPrintBuilt from vendor docs Status, temperatures, progress, start, pause and cancel, and sending a sliced file, using an API key. Tested against a real OctoPrint server, but not with a physical printer attached. No camera.
PrusaLinkBuilt from vendor docs Status, progress and controls, and sending and starting a sliced file, using the PrusaLink password. No camera. Slicing profiles for the Prusa models, including the MMU3 (CORE One, MK4S, MK3.9, MK3.5) and the XL 5T for multi-colour, all untested on a real printer.
Creality (K1, K2, Hi; CFS) Next updateBuilt from open-source slicer code Status and the CFS slots over the printer's own network, and sending a sliced file to it. Starting the print from Nozzle It All is not switched on yet: you start it on the printer's screen. No pause, resume or cancel, no camera. Tested against simulated printers only.
Flashforge (AD5X, 5M; IFS) Next updateBuilt from open-source slicer code Status and the IFS slots through the printer's local API, and sending a sliced file to it, using its serial number and access code. Starting the print from Nozzle It All is not switched on yet: you start it on the printer's screen. No pause, resume or cancel, no camera. Tested against simulated printers only.
Anycubic (Kobra 3, S1, Kobra X; ACE) Next updateBuilt from open-source slicer code On stock firmware with LAN mode on: status and the ACE / ACE Pro slots over the printer's own network (you enter only its address), and sending a sliced file to it. Starting the print, pause, resume, cancel and other controls from Nozzle It All are not switched on yet: use the printer's screen. Tested against simulated printers only.
Snapmaker 2.0 (A150, A250, A350) Next updateBuilt from open-source slicer code With the 3D printing module attached (single or dual extruder, with or without the Quick Swap Kit): status through the touchscreen's own network API, and sending a sliced file to it. You connect from Edit printer and accept on the printer's touchscreen. Starting the print, pause, resume and cancel from Nozzle It All are not switched on yet: use the printer's screen. Laser and CNC modules aren't supported. Tested against simulated printers only.
Snapmaker J1 and Artisan Next updateBuilt from open-source slicer code Sending a sliced file over the printer's own network, after you accept the connection on its screen. Printer state isn't read yet, and starting the print, pause, resume and cancel from Nozzle It All are not switched on: use the printer's screen. Tested against simulated printers only.
Older Flashforge (Adventurer 3/4, Creator, Guider) Next updateBuilt from open-source slicer code Sending a sliced file over the printer's older network console, when no serial number and access code are entered. Printer state and filament slots aren't read yet, and starting the print from Nozzle It All is not switched on: start it on the printer's screen. Tested against simulated printers only.
Duet / RepRapFirmware Next updateBuilt from open-source slicer code Sending a sliced file to a Duet board, with or without Duet Software Framework. Printer state isn't read yet, and starting the print from Nozzle It All is not switched on: start it on the printer's screen or its web interface. Tested against simulated printers only.
UltiMaker S-series Next updateBuilt from open-source slicer code Status over the printer's local network API, after you approve Nozzle It All on the printer's screen. An UltiMaker prints every job it is sent, and starting a print from Nozzle It All is not switched on yet, so nothing is sent for now. The UltiMaker 2 has no network. Tested against simulated printers only.
Repetier-Server Next updateBuilt from open-source slicer code Sending a sliced file to a printer behind Repetier-Server. Printer state isn't read yet, and starting the print from Nozzle It All is not switched on: start it in Repetier-Server. Tested against simulated printers only.

Which app does what

The Android app connects to every printer type in this table itself; Nozzle It All for Desktop connects to all of them except Creality, Flashforge, Anycubic, the older Snapmaker models (2.0, J1, Artisan), Duet, UltiMaker and Repetier-Server. Nozzle It All Web runs in your browser, which can only talk to Klipper-based printers (including the Snapmaker U1) directly, and only when the browser allows it; for everything else it goes through Nozzle It All for Desktop on your own computer, which you pair with the browser once. Nothing goes through a Nozzle server, and a printer's password, access code or API key stays in the app you added it to.

Only the Snapmaker U1 on stock firmware can use a maker's online account, and only if you switch that on. No other printer needs an account with its maker or with us.

Something not on the list?

If your printer runs Klipper with Moonraker, it will very likely work as "Klipper with Moonraker" even if the model is not named here. Tell us what you find at {{email}}, or open an issue.
