Support

Email is the main way to reach us. GitHub is there for bugs and ideas that are best discussed in public.

GitHub Issues

For bugs you can reproduce and for feature requests. Others can see and add to them.

Open an issue

What to include

  • What you did, what you expected, and what happened instead.
  • The app version (Settings, About & credits) and your Android version and phone.
  • Your printer type and firmware, for example "Klipper on a Voron 2.4" or "Snapmaker U1".
  • A screenshot or short screen recording if it helps.

Never send or post a password, API key or access code. If a screenshot shows one, hide it first. We will never ask for one.

Security problems

If you think you have found a security problem, please email {{email}} with the subject "Security" and do not post it publicly. We will reply and work with you on a fix before details are shared.

Before you write

  • Platforms lists what exists today. Only the Android app does.
  • Some printers are confirmed on real hardware and some are built from vendor documentation. If yours is in the second group, tell us what worked and what did not. That helps a lot.

We are a small project and reply as soon as we can.
