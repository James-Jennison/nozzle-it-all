Test the Android app

Nozzle It All for Android is in invite-only closed testing on Google Play. This page explains how to join, what to try, and how to tell us what you find.

Join the test

  1. Be on the invite list. Only people we have added can install the test build. If you are not on the list, email us to request a spot and include the Google account address you use on Google Play.
  2. Open the join link while signed in to that Google account: play.google.com/apps/testing/com.nozzleitall.app. Choose to become a tester.
  3. Install from Google Play using the link on that page. It installs like any other app.

Please stay opted in for 14 days. Google requires a set number of testers to stay in the test for two weeks before an app can be released to everyone. Leaving early, or uninstalling and opting out, sets that clock back for everyone.

What to try

You do not need to try everything. Whatever you have time for helps.

  • Slice a model on your phone. Pick a model, slice it, and look at the layer preview. Tell us if it fails, crashes or looks wrong.
  • Connect a printer you own, if you have one, and check that the dashboard and controls match what the printer is doing. See Supported printers for what has been checked on real hardware.
  • Browse free models from MyMiniFactory in Discover.
  • Turn on background print alerts in Settings and see whether you are told when a print finishes or fails.
  • Use it the way you normally would and note anything confusing or broken.

You do not need a printer to test slicing and browsing.

Tell us what you find

  • Email {{email}} for anything, including private problems.
  • GitHub Issues: for bugs you can reproduce, open an issue. Others can see and add to it.

Please include the app version (Settings, About & credits), your phone and Android version, and your printer type if it matters. The Support page has the full list.

Never send or post a password, API key or access code. If a screenshot shows one, hide it first.

Testing on your own printer

If you have a printer to try it on, there is a separate step-by-step guide for testing on real printers, with a test file and a report form.

What to expect

  • This is an early build. Things will be missing or rough.
  • There is no account and no analytics. What the app does with your data is on the Privacy page.
  • The app is free and open source. Its source is on GitHub.

Thank you for helping test it.
