The slicing engine

Every version of the app slices with nozzle-engine, which is also AGPL-3.0. It is OrcaSlicer's engine by way of Snapmaker Orca, with our changes to run it headless on Android, in the browser and on the desktop. Each change is its own commit in that repository. The app pins the exact version it ships:

  • Engine commit: 9a9f2319d89a (its change history)
  • The pin file, and the Android dependency archives with their checksums.

Building it

The repository's README explains how to build the Android app with Gradle and how to prepare the pinned engine. A script in the repository checks the dependency archives against their pinned checksums.

If you use it over a network

The AGPL asks that people who use modified versions over a network can get the source of that version. If you run a modified copy of any part of Nozzle It All (for example a modified copy of Nozzle It All Web hosted for other people), you need to offer its source to its users. The licence text says exactly how.
