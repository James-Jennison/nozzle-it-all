Supported printers

Nozzle It All connects to the printers you own over your own network. We are honest about how sure we are, so every printer type below is one of two things:

Verified on hardware we have run it on a real printer of this kind.
Built from vendor docs written against the vendor's published protocol and tested against an emulator or test server, but not yet on a real printer. It may work well, and it may not. If you try one, please tell us what happened.

Printer or firmwareStatusWhat it does
Klipper with MoonrakerVerified on hardware Status, temperatures, progress, start, pause and cancel, file browser, macros, camera, jog, bed levelling, timelapse and filament load and unload, each shown only if the printer reports it. Sliced files can be sent to it.
Snapmaker U1 (PAXX firmware)Verified on hardware The primary platform. Everything above, plus its four toolheads: the material loaded in each one, Full Spectrum colour mixing and multiACE. Works entirely on your own network with no Snapmaker account, cloud or internet connection; away from home, connect through your own private network such as Tailscale. A bundled slicing profile is included. Bespok3d, an add-on manager for the printer, does not work on this firmware.
Snapmaker U1 (stock firmware)Built from vendor docs Monitoring, controls, sending jobs and the slicing profile over your own network, plus optional pairing with Bespok3d on Android. Some stock-firmware features exist only through Snapmaker's own cloud; on Desktop those will come through optional Stock U1 support, installed separately and only started if you add a Stock U1. If it fails, your PAXX printers are unaffected. Nothing here has been run on a stock-firmware U1 yet, so treat it as untested and tell us how it goes.
Elegoo Centauri Carbon running OpenCentauriVerified on hardware Works as a Klipper-style printer with a bundled slicing profile. You confirm the firmware version once, because slicing with the wrong profile can stop a print on some firmware.
Bambu Lab (LAN mode)Built from vendor docs Status, pause, resume and stop, and sending a sliced file, over the printer's local network. The camera works on the A1 and P1 series; the X1 and H2 series use a camera stream Nozzle It All can't show yet. Needs LAN mode, the printer's serial number and access code. The app remembers each printer's certificate the first time it connects and warns you if it later changes. Tested against an emulator only.
OctoPrintBuilt from vendor docs Status, temperatures, progress, start, pause and cancel, and sending a sliced file, using an API key. Tested against a real OctoPrint server, but not with a physical printer attached. No camera.
PrusaLinkBuilt from vendor docs Status, progress and controls, using the PrusaLink password. No camera. A bundled Prusa slicing profile exists, also untested on a real printer.

Have one of these printers? Help us test it. See every printer model with a bundled slicing profile (376 models from 60 makers). Slicing works for all of them; connecting to and controlling a printer is limited to the types in this table.

Which app does what

The Android app and Nozzle It All for Desktop connect to every printer type in this table themselves. Nozzle It All Web runs in your browser, which can only talk to Klipper-based printers (including the Snapmaker U1) directly, and only when the browser allows it; for everything else it goes through Nozzle It All for Desktop on your own computer, which you pair with the browser once. Nothing goes through a Nozzle server, and a printer's password, access code or API key stays in the app you added it to.

Only the Snapmaker U1 on stock firmware can use a maker's online account, and only if you switch that on. No other printer needs an account with its maker or with us.

Something not on the list?

If your printer runs Klipper with Moonraker, it will very likely work as "Klipper with Moonraker" even if the model is not named here. Tell us what you find at support@nozzleitall.com, or open an issue.
