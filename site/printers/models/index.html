Slicing profiles

The app bundles OrcaSlicer's own slicing profile for these printer models, so you can slice a model on your phone for any of them. Choose yours when you add a printer. A bundled profile does not mean the app can control that printer: see Supported printers for what it can connect to.

Almost none of these has been run on a real printer yet. Each profile loads and slices in the app on a real phone, but that does not prove the printed result on your machine. Watch the first print. Only models marked "Verified on hardware" have been printed with the app. If you try one, please tell us how it went.
